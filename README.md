# 🎯 Linea Airdrop Checker & Claimer

Профессиональный инструмент для проверки права на получение токенов Linea airdrop и автоматического клейма с базой данных и экспортом результатов.

## ✨ Возможности

- 🔍 **Проверка права на airdrop** - проверяет аллокацию для любого адреса
- 🚀 **Автоматический клейм** - клеймит токены с настраиваемыми задержками
- 🔐 **Безопасное хранение ключей** - система шифрования приватных ключей AES-256-CBC
- 📊 **База данных SQLite** - кэширование результатов проверки для быстрого доступа в базу данных
- 📈 **Экспорт в XLSX** - экспорт данных в Excel с фильтрацией по типам кошельков
- 💎 **Проверка баланса** - отображает текущий баланс токенов
- ⚡ **Параллельная обработка** - быстрая проверка множества адресов
- 🎨 **Красивые таблицы** - профессиональное отображение результатов в консоли

## 📋 Использование

### Главное меню

При запуске `npm start` доступны следующие режимы:

1. **🔍 Проверка Eligble** - проверка права на получение токенов
2. **🚀 Клайм** - автоматическое получение токенов
3. **📊 Экспорт данных в XLSX** - экспорт результатов в Excel
4. **❌ Выход** - завершение работы

### Режим проверки

1. Создайте файл `keys.txt` с приватными ключами (по одному на строку)
2. Запустите приложение: `npm start`
3. Выберите "🔍 Проверка Eligble"
4. Система автоматически:
   - Извлечет адреса из приватных ключей
   - Проверит данные в базе данных (быстро)
   - Выполнит RPC-запросы для новых адресов (параллельно)
   - Отобразит красивую таблицу с результатами
   - Покажет общую статистику

### Режим клейма

1. Запустите приложение: `npm start`
2. Выберите "🚀 Клайм"
3. Настройте задержки между клаймами (опционально)
4. Система автоматически:
   - Проверит право на получение для каждого кошелька
   - Выполнит клайм для eligible кошельков
   - Покажет прогресс и статистику

### Режим экспорта

1. Выберите "📊 Экспорт данных в XLSX"
2. Выберите тип экспорта:
   - **Все кошельки** - полная база данных
   - **Только eligible** - кошельки с правом на получение
   - **Только unclaimed** - кошельки, которые еще не получили токены
3. Получите Excel файл с результатами

## 🔐 Безопасность

### Файлы конфигурации

#### keys.txt - Приватные ключи
Создайте файл `keys.txt` с вашими приватными ключами (по одному на строку):
```
0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef
0xabcdef1234567890abcdef1234567890abcdef1234567890abcdef1234567890
```

> **Примечание**: Ключи могут быть с префиксом `0x` или без него. Система автоматически добавит префикс при необходимости.

### Автоматическое шифрование приватных ключей

Проект автоматически управляет безопасным хранением приватных ключей с использованием **AES-256-CBC** шифрования:

#### Алгоритм шифрования:
- **Алгоритм**: AES-256-CBC
- **Деривация ключа**: PBKDF2 с 100,000 итераций, SHA256
- **Соль**: 32 случайных байта
- **IV**: 16 случайных байт для каждого шифрования

#### Процесс шифрования:
1. **При запуске приложения** система автоматически предложит зашифровать ключи из `keys.txt`
2. **Введите пароль** для шифрования (минимум 6 символов, чем больше тем лучше)
3. **Подтвердите пароль**
4. **Удалите `keys.txt`** вручную после успешного шифрования

> **Важно**: Шифрование происходит автоматически при первом запуске, если обнаружен файл `keys.txt`

#### Использование зашифрованных ключей:
- При запуске в режиме клейма система автоматически предложит ввести пароль
- При неверном пароле будет запрошен повторный ввод с понятным сообщением
- Ключи расшифровываются только в памяти и не сохраняются
- Создаются файлы `keys.encrypted` и `keys.salt` для безопасного хранения

## ⚠️ Важные замечания

1. **Безопасность**: Никогда не передавайте приватные ключи третьим лицам
2. **Резервные копии**: Сохраните зашифрованные файлы `keys.encrypted` и `keys.salt`
3. **Пароль**: Запомните пароль для расшифровки - восстановить его невозможно

5. **База данных**: Результаты проверки сохраняются в `database.db` для быстрого доступа
